# Minesweeper: Level Rush

Official browser demo of **Minesweeper: Level Rush**.

## Play

https://corriscant.github.io/minesweeper-level-rush/

## Android version

https://play.google.com/store/apps/details?id=com.corriscant.minesweeper

## About this repository

This repository contains the deployable WebGL build only.
The Unity project and source code are not included.

Progress in the browser version is stored locally in the browser and is not synchronized with the Android version.

## Analytics configuration

The WebGL page includes optional Google Analytics 4 funnel tracking. Set the production Measurement ID in the single configuration file:

```text
analytics-config.js
```

Replace `G-XXXXXXXXXX` with the Web data stream's Measurement ID. While the placeholder remains, the Google tag is not loaded and analytics calls are safely ignored.
